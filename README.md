# Dropout Fashion-MNIST Blog Project

- `index.md` — blog post draft with figures and saved-output results.
- `dropout_fashion_mnist_experiment.ipynb` — the experiment notebook supplied for this project.
- `figures/` — three plots extracted from the notebook's saved outputs.

## Before submitting
1. Open the notebook in Google Colab or Jupyter and run it yourself.
2. Confirm the resulting metrics match the values described in `index.md`. If they differ, update the article and replace the figures.
3. Check the notebook configuration: this saved run uses 10,000 training images and 5 epochs.
4. Upload the files to a GitHub repository, enable GitHub Pages, and test the published URL in a private browser window.
5. Make sure you understand the experiment and can explain it in your own words.

The article's results are based on the saved outputs in the uploaded notebook and should be verified by rerunning the experiment before submission.
